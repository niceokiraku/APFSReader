# APFSReader 使い方(バージョン 0.9.0 ベータ)

APFSReader は、Mac で使っているディスク(**HFS+** / **APFS**)を、Windows のエクスプローラーから
**読み取り専用**で開けるようにするソフトです。ディスクイメージ(`.dmg` など)と、接続した Mac 用の
ディスクの両方に対応します。ディスクには一切書き込みません。

> **ベータ版です。** 物理ディスクの読み取りは、実機での検証がまだ済んでいません。
> 大切なデータは、必ずコピーを残してから使ってください。

## 動作環境

- Windows 10 / 11(64 ビット)
- **WinFsp**(無償のファイルシステムドライバー)。入っていない場合、アプリが案内を表示します。
  セットアップ時に自動で入れることもできます。

## インストール

- **セットアップ版**:`APFSReader-Setup-0.9.0.exe` を実行します。通常は管理者権限なしでインストールされます。
- **ZIP 版**:好きなフォルダーに展開し、`apfsreader-gui.exe` を実行します(`apfsreader-broker.exe` と同じフォルダーに置いてください)。

署名のない配布のため、初回に Windows が「WindowsによってPCが保護されました」(SmartScreen)と表示することがあります。
その場合は **「詳細情報」→「実行」** を選んでください。ウイルス対策ソフトが誤って検出することがある場合も、
このソフトの動作は「ディスクの読み取りと、仮想ドライブとして見せること」だけです。

## ディスクイメージを開く

1. `apfsreader-gui.exe` を起動します。
2. 「**イメージを追加**」を押すか、`.dmg` などのファイルをウィンドウにドロップします。
3. 中のボリュームが一覧に出ます。ドライブ文字(「自動」でも構いません)を選んで「**マウント**」を押します。
4. エクスプローラーに新しいドライブが現れます。「**フォルダーを開く**」からも開けます。
5. 終わったら「**マウント解除**」を押します。

APFS のディスクに複数のボリュームがある場合は、Mac のユーザーファイルがある **Data** ボリュームが「おすすめ」になります。

## 接続した Mac 用ディスクを開く

「**物理ディスク**」の見出し(▼)をクリックして開きます。

1. 目的のディスクの「**ディスクを読み取る**」を押します。
2. 管理者権限の確認画面(UAC)が出ます。承認すると、**読み取り専用の小さなヘルパー**だけが管理者権限で動きます。
   アプリ本体とドライブは通常の権限のままなので、エクスプローラーに普通に表示されます。
3. ディスクの中身が調べられ、ボリュームが一覧に出ます。あとはイメージと同じです。

ヘルパーは、選んだ 1 台のディスクを読み取るだけで、書き込む機能を持ちません。アプリを閉じると自動で終了します。

## トレイと終了

ウィンドウを閉じる、または最小化すると、アプリは**システムトレイ**(通知領域)に残り、通知でお知らせします。
トレイのアイコンをクリックすると戻ります。右クリックのメニューから「すべてアンマウント」「終了」もできます。
終了すると、マウント中のボリュームはすべて解除されます。

## できること・できないこと

| できる | できない / 注意 |
|---|---|
| HFS+(ジャーナル付きを含む)、HFSX、APFS の読み取り | **暗号化された APFS**(FileVault など)は開けません(一覧に表示され、理由が出ます) |
| `.dmg`(zlib / bzip2 / LZFSE / LZMA / ADC)、生イメージ、GPT / Apple パーティションマップ | Fusion Drive、APFS のスナップショット |
| ハードリンク、リソースフォーク、拡張属性、透過圧縮されたファイル | 一部の新しい圧縮形式(LZBITMAP)のファイルは、読み取ると警告が出ます |
| 日本語などのファイル名(Windows で使えない文字は似た文字に置き換えて表示) | シンボリックリンクは、リンク先のパスが書かれた小さなファイルとして見えます |

HFS+ のディスクを Mac で正しく取り外さなかった場合でも、ログ(ジャーナル)の内容を反映した状態で読みます。
ディスクへの書き込みはしません。

## コマンドライン(上級者向け)

```
apfsreader disks                         接続されているディスクの一覧
apfsreader info    image.dmg             中身の概要
apfsreader ls      image.dmg /Documents  フォルダーの一覧
apfsreader extract image.dmg /Documents D:\rescued
                                         フォルダーごとコピー(読み取りエラーがあっても続行し、最後に報告)
apfsreader-mount   image.dmg R:          ドライブとしてマウント(Enter か Ctrl+C で解除)
```

## 困ったとき

- **「WinFsp が必要です」と出る**:ダウンロードページから WinFsp をインストールし、「再確認」を押します。
- **物理ディスクの承認画面で「いいえ」を押した**:読み取りは行われません。もう一度「ディスクを読み取る」を押してください。
- **「ディスクを読み取り用に開けませんでした」**:他のソフトがそのディスクを使っている可能性があります。
- **暗号化のため開けない**:FileVault などで暗号化されたボリュームには対応していません。
